# Mehmet Tugsuz

M.S. Economics, Arizona State University (December 2026). I work on experiments, causal inference and product analytics in SQL, Python and R.

## Projects

- **[headline-ab-tests](https://github.com/tugsuz/headline-ab-tests)**: 22,741 real A/B tests. Sample ratio checks, power, peeking, false discovery control, weekly monitoring in SQL, and a shipping rule checked on held-out traffic.
- **[ecommerce-product-metrics](https://github.com/tugsuz/ecommerce-product-metrics)**: sessions, a purchase funnel and retention cohorts in SQL on DuckDB and BigQuery, an A/A test, and a [public dashboard](https://datastudio.google.com/reporting/99fad1d3-2726-4dc1-9d05-0afa8c49a474).
- **[alpha-decay](https://github.com/tugsuz/alpha-decay)**: what happens to 189 published stock signals after publication, and how look-ahead bias inflates machine learning backtests. [Paper](https://tugsuz.github.io/alpha-decay/).
- **[fomc-factor-structure](https://github.com/tugsuz/fomc-factor-structure)**: M.S. thesis, in progress. An intraday event study of Federal Reserve statements.
